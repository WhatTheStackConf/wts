## Deployment and import

Deploy the additive `speakers.is_mc` schema and MC-aware public UI **before** publishing these profiles. Otherwise the old public UI incorrectly promises an unannounced talk for MC-only profiles. The importer refuses absent/incompatible MC schema.

Take and verify a fresh native PocketBase backup and separate recovery coverage for original uploads stored outside PocketBase. Private audit directories must be mode 0700 and outside the repository. The acknowledgements below do not create or validate a native backup themselves.

```sh
python3 -B scripts/mc-2026.py dry-run
python3 -B scripts/mc-2026.py stage --execute --exclusive-writer --native-backup-verified --backup-dir PRIVATE_DIRECTORY
python3 -B scripts/mc-2026.py publish --execute --exclusive-writer --native-backup-verified --backup-dir PRIVATE_DIRECTORY
python3 -B scripts/mc-2026.py verify
python3 -B scripts/mc-2026.py publish --execute --exclusive-writer --native-backup-verified --backup-dir PRIVATE_DIRECTORY
```

Use the established `WTS_PB_URL` / `WTS_PB_API_KEY` environment variables or the literal loader from `~/.zshrc`; credentials and token-bearing URLs are never printed. To use refreshed literal assignments instead of stale inherited values, prefix each command with `env -u WTS_PB_URL -u WTS_PB_API_KEY`.

Staging copies originals into new, unpublished profiles, reading back fields and photo checksums after each upload. A lost committed upload response is reconciled by exact identity, never by creating another profile. Same-name/slug collisions and unexpected existing values fail closed.

Publication requires the already-enabled batch API and flips all four publication flags in one transaction. Completed reruns perform zero writes. Every operation compares unchanged records across the agenda/source collections; no other speaker, event, Session or timetable record may change.
